# 3. I Am Not Sure What Information Matters

## This May Happen When
* Large amounts of information appear potentially relevant.
* You are unsure which information is most relevant to the project.
* You cannot determine which information deserves further analysis.

## Questions to Ask Yourself
* Which information appears most relevant?
* Which information can be set aside?
* Which information directly supports the project objective?
* Which information helps answer the project question?

## Possible Approaches
* **Prioritization.** Determine which information deserves greater attention based on its importance, usefulness, relevance, or analytical value.
* **Relevance Assessment.** Evaluate whether information directly supports the project's objective, question, observations, findings, or conclusions.
